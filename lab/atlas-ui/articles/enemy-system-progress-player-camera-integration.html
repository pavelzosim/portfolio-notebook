01 Overview

This development update covers the modular enemy system and the first phase of player and camera integration in Unity. The focus is on connecting spawning, combat, movement and camera behaviour in a working prototype.

[ ENEMY SYSTEM ]
ComponentImplementation
DataEnemy configuration stored in ScriptableObjects.
CombatModular health and attack systems.
MovementChaser and ranged-unit patterns.
LootDrops triggered by enemy death events.
SpawningNavMesh sampling for spawn placement.

The player controller combines eight-directional movement, melee combat, health and scoring through Unity’s Input System. The camera uses smooth following, boundary triggers and optional dead zones for a beat ’em up-style presentation.
