[HOW TO USE]

  1. Load an image and select its interpretation.
  2. Tune Height and Normal; previews update after edits.
  3. Adjust each estimated map separately.
  4. Inspect the selected map and the lit material.
  5. Choose export resolution and download PNG or ZIP.

[DATA]

  • Photographs do not measure height. Shadows and highlights can become false relief.
  • Roughness and AO are artist-controlled estimates, not recovered physical properties. Metallic is not inferred.
  • PNG uses raw 8-bit channels; JPEG/WebP use browser decoding. Albedo mode converts sRGB luminance to linear.
  • Image brightness is an artistic starting point for relief, not measured geometry.
  • Data PNGs omit color metadata; import with sRGB off.

[LIMITS]

  • WebGL 2 + floating-point targets required
  • 64 MiB per image · 4096 px per side
  • 256 / 512 px live previews; square crop without stretching
  • Up to 4096 px export, subject to GPU limits
  • PNG: 8-bit non-interlaced
  • Large exports can take several seconds; settings lock while processing.

[SEAMLESS]

  • Boundary blending is applied before derived maps. It can alter edge detail; disable it if the source is already tileable.
  • Maximum edge differences help inspect seams. Matching border values alone do not guarantee an invisible repeated pattern.
