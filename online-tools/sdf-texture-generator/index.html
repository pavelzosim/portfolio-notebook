[HOW TO USE]

  1. Load transparent PNG, SVG or WebP. Use luminance for JPG.
  2. Set range, threshold and padding. Preview updates after edits.
  3. Inspect SDF or reconstructed shape; scroll and drag to inspect edges.
  4. Choose Outline, Glow, Dissolve or Soft edge.
  5. Export PNG. Disable sRGB on engine import.

[ENCODING]

SDF = clamp(0.5 + d / (2R), 0, 1). Inside is positive. Edge offset shifts d before encoding. Invert reverses the sign before offset.

The field is exact for the thresholded raster pixel-cell boundary. Rasterization and thresholding approximate the original vector contour; this is not MSDF.

[IMPORT]

Unreal and Unity: disable sRGB; sample the red channel. Use linear filtering. Compression and ordinary mipmaps can move the edge; validate your target settings. Wider ranges reduce 8-bit precision (2R / 255 pixels per step).

[SHADERS]

Unreal Custom node / Unity custom function: supply a linear SDF texture sample as sdf, UV and width parameters in output pixels. Shader Graph can use the equivalent Subtract, Multiply and Smoothstep nodes.
[LIMITS]
256–4096 square output; aspect ratio preserved by default. Preview uses 512 px; range and padding are scaled from export pixels. 4K exact EDT needs roughly 250–350 MiB of working memory, depending on browser decoding/PNG encoding. Cancel terminates the worker.
SVG supports inert geometry, gradients and local references. Active content, stylesheets, fonts, embedded images and external resources are rejected. SVG 2× sampling supports exports up to 2048 px; choose 1× for 4K. It antialiases rasterization before thresholding; exported fields remain unblurred.
