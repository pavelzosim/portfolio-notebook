[HOW TO USE]

  1. Add source masks.
  2. Choose a preset; verify assignments.
  3. Set resolution and resize mode.
  4. Assign sources and adjust each channel; previews update automatically.
  5. Generate full resolution and export; disable sRGB on engine import.
[DATA]
  • PNG: raw 8-bit channels; profiles ignored.
  • JPEG: browser decoding; values may differ from other decoders.
  • RGB under zero alpha is preserved in PNG export.
  • Levels → gamma → inversion.
  • Do not treat tangent normals as scalar masks.
[LIMITS]
  • 16 PNG/JPEG sources
  • 8-bit non-interlaced PNG
  • 64 MiB per file; 128 MiB batch
  • 64 million source pixels
  • 8192 px source side
  • 4096 px output side
[ENGINE IMPORT]
  • Unreal ORM: R AO · G roughness · B metallic.
  • Unity HDRP: R metallic · G AO · B detail mask · A smoothness.
  • Unity URP: assign the packed map to both Metallic and Occlusion.
  • Packing does not guarantee GPU-memory savings.
