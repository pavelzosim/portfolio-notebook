    § 04

    How to use

    1. Add image files or a folder. New batches use natural filename order.
    2. Use the up/down controls or drag frames to set the animation order. Empty frames are labelled and retained.
    3. Play the animation and adjust the delay.
    4. Apply a grid recommendation or set columns manually. Nearest square reserves square rows; manual columns use automatic rows.
    5. Choose Exact grid for unchanged pixels, then download the PNG.

    Limits and privacy

    PNG and JPEG images only. To protect browser memory, this tool accepts at most 512 frames, 256 MiB of source files, and 32 million decoded pixels. Canvases are limited to 8192 pixels per side and 32 million pixels. Large sequences may need the desktop version.

    Files are read into memory and are never uploaded by the tool. Clear frames or close the page to release them. The page may load site fonts, consent-based analytics, and the optional Buy Me a Coffee button.
