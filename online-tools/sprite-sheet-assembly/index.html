    Exact grid preserves source dimensions and alpha. POT rescale changes pixel dimensions and may distort artwork; review the X/Y scales before exporting.

    [HOW TO USE]

    1. Add images or a folder. Files use natural filename order.
    2. Drag frames or use up/down controls to set the order. Empty frames are retained.
    3. Play the animation and adjust the delay.
    4. Set columns or choose a grid recommendation. Rows are calculated automatically; Nearest square reserves square rows.
    5. Choose Exact grid for unchanged pixels, then download the PNG.

    [LIMITS]
