    § 02

    Texture settings

    APPLIED TO THE BATCH

    No upscaling. Maximum edge preserves aspect ratio; POT snaps each axis separately and can distort the image.

    JPEG/WebP are for visual images. Use PNG without resizing for data textures.

    § 03

    Inspect the result

    SELECT AN IMAGE ABOVE

    Hover or tap an image for a linked 100% loupe. Each image pixel occupies one CSS pixel; both panels inspect the same relative position. Keyboard: focus a preview, use arrow keys, Escape to close.

    Previews fit the panel and use at most 1024 px per edge. Download the file for full-resolution inspection in your image editor or engine.

    § 05

    Technical boundaries

    This is an 8-bit browser image workflow, not GPU texture compression. It does not export BCn/ASTC, mip chains, HDR/EXR or KTX/DDS. Canvas re-encoding does not preserve original EXIF or ICC metadata; no linear-light resampling or normal-vector renormalisation is performed. Animated inputs produce a still frame.

    For normal maps, roughness, masks and packed channels, use the Data texture preset: PNG, original dimensions and alpha retained. PNG encoding is lossless, but browser decoding and colour handling are not a guarantee of bit-exact preservation of every source asset. Verify data textures in your pipeline. PNG optimisation with palette reduction or a specialised lossless compressor is not included.

    Limits: 10 images, 100 MiB of source files, 48 million decoded pixels across the batch, and 8192 px per edge. Limits are checked after decoding; very large files may exceed device memory. Outputs are processed one at a time. Clear the batch to release images.

    Image bytes are processed locally and never uploaded by this tool. The page can load fonts, consent-based analytics and the official support button.
