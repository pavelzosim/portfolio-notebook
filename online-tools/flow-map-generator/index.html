[ENCODING]

+X right, +Y down in the PNG. Byte 128 is exactly neutral. Below 128 decode (b−128)/128; otherwise (b−128)/127. Standard RG×2−1 has a 1/255 neutral bias; use a dead zone if required.

[ENGINE IMPORT]

Disable sRGB. Use linear mask data and inspect compression. No universal DirectX/OpenGL flow Y flip: match the shader UV convention.

Decode RG, then offset UV by flow × strength × phase. Two phases with half-cycle offset reduce reset popping.

// HLSL · exact neutral RG decode
float2 b = rg * 255.0;
float2 flow = (b - 128.0) /
  lerp(float2(128,128), float2(127,127), step(128.0,b));
float2 uvA = UV - flow * Strength * frac(Time * Speed);
float2 uvB = UV - flow * Strength * frac(Time * Speed + 0.5);
float w = abs(frac(Time * Speed) * 2.0 - 1.0);
// lerp(colorSample(uvA), colorSample(uvB), w)

Unity Shader Graph / Unreal Material Graph: Sample RG, decode, multiply by phase and strength, subtract from UV, sample color twice and blend. GLSL uses vec2 / mix / fract.

[LIMITS]

256 px editable paint/import layers, 4000 stamps per project, 8 layers, 20 undo snapshots. Procedural fields recompute at export resolution up to 4096. Imported PNG ≤16 MiB / 4096 px; project ≤32 MiB. Painting does not add detail beyond its 256 px grid.
