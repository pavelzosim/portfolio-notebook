# TOOL-010 — UV & Texel Density Toolkit

Status: planned. Not implemented or released. Registry: content/online-tools/index.json.

Tenth Online Tool.

## Intended scope

Generate UV checkers; calculate texel density; visualize UV stretching and inspect imported model UVs. Accept target pixels per meter and object dimensions to estimate a suitable texture resolution.

## Decisions before implementation

Make world units, transforms, UV area and texture aspect ratio explicit. Separate a dimension-only estimate from mesh-area measurement. Define treatment of overlapping UVs, multiple UV sets, materials and UDIMs before implementation.
